# 島嶼尋光｜公民課對話闖關

國中公民課的對話式闖關遊戲。這個儲存庫是遊戲網站本身，由 GitHub Pages 直接發布。

| 檔案 | 用途 |
|---|---|
| `index.html` | 遊戲頁面，含學生的遊戲畫面和「老師後台」 |
| `config.js` | 後台網址（Google Apps Script 網頁應用程式，結尾是 `/exec`） |
| `img/` | 遊戲用的圖片 |

劇情、題目、答案、學生帳號與成績都不在這裡，存放在老師的 Google 試算表。

這個網站由 Claude 維護。要修改畫面或功能，請在 Claude 專案「課程遊戲化網站」裡提出。
